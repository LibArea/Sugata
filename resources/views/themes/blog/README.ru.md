# Тема оформления «blog»

Блог-тема, построенная поверх базовой темы `wiki`. Демонстрирует переопределение
структуры главной и статьи без изменения ядра и контроллеров.

## Чем отличается от wiki

| Зона | wiki | blog |
|---|---|---|
| Шапка | полный заголовок + табы | лёгкая шапка + поиск, **меню-чипы** |
| Главная | секции растянуты в одну колонку | **двухколоночная сетка**: лента постов + правый сайдбар |
| Hero-пост | маленькая карточка справа | **большой «пост дня»** с обложкой на всю ширину |
| Сайдбар | нет | «популярные», «рубрики», «вы знали», статистика |
| Статья | боковая toc-колонка | **узкая колонка** + обложка сверху, related как лента |

## Структура папки

```
resources/views/themes/blog/
├── theme.php                          манифест (parent = wiki)
├── assets/css/blog.css                стили блога (подключаются после app.css)
└── site/
    ├── layouts/
    │   ├── article.php                блог-layout статьи (переопределяет wiki)
    │   └── partials/header-body.php   блог-шапка + чипы-меню
    └── pages/
        └── home.php                   блог-главная с сайдбаром
```

Блог **не копирует** каркас: `header.php`, `footer.php`, компоненты, страницы
списков/facts/articles/sites наследуются из `wiki` через цепочку `blog → wiki`.

## Манифест

```php
return [
    'name'   => 'blog',
    'parent' => 'wiki',
    'css'    => ['assets/css/blog.css'],
    'js'     => [],
];
```

## Включение

В `config/general.php`:

```php
'template' => 'blog',   // или 'wiki' — вернуть дефолтную
```

После смены темы **обновите страницу жёстко (Ctrl+F5)**, т.к. номер версии в URL
(`?108`) при смене темы не меняется, и браузер может держать кеш.

## Как это работает

- `<body>` получает класс активной темы (`<body class="blog">`) из общего
  `wiki/site/layouts/header.php` — все блог-правила CSS идут под `body.blog`.
- `pages/home.php`, `layouts/article.php` и `partials/header-body.php` находятся
  **только** в блоге; при `template=blog` резолвер отдаёт их, всё остальное — из wiki.
- `blog.css` копируется в `public/assets/` (метод `Theme::publishAssets()`) —
  вызывается при рендере и при статической сборке.

## Кастомизация

Чтобы доработать блог под себя:

- **Цвета / компоновку** — править `assets/css/blog.css` (используйте токены `var(--*)` из app.css).
- **Шапку** — `site/layouts/partials/header-body.php`.
- **Главную** — `site/pages/home.php` (список доступных данных см. ниже).
- **Статью** — `site/layouts/article.php`.

### Данные, доступные на блог-главной (`home.php`)

Все передаются из контроллера без изменений:

| Переменная | Содержимое |
|---|---|
| `$featuredBig` / `$bestFacts` | главный/избранный пост |
| `$items` | свежие записи |
| `$didYouKnow` | блок «вы знали» |
| `$sections` | дерево рубрик (корневые с детьми) |
| `$popular` | популярные |
| `$stats` | счётчики: `facts`, `articles`, `sites`, `categories` |
| `$mod` | `static` \| `preview` |

## Требования

- Работает со статической сборкой и предпросмотром.
- Не требует правки контроллеров или схемы БД.

# Система тем

Каталог тем оформления публичного сайта. Каждая тема — папка в `resources/views/themes/`.
Активная тема выбирается в `config/general.php` ключом `'template'`.

## Структура

```
resources/views/themes/
├── wiki/        дефолтная (корень цепочки) — wiki
└── blog/        наследует wiki, переопределяет главную и статью
```

## Принцип работы

**Резолвер** (`App\Content\Theme`) по пути вида `site/...` ищет файл по цепочке тем:

1. активная тема → `themes/{template}/site/...`
2. её родитель → `themes/{parent}/site/...`
3. ... и так вверх по `parent`
4. аварийный фолбэк → `themes/wiki/site/...`

Если файла нет нигде — возвращается исходный путь, HLEB покажет ошибку
«file not found» (честный отказ, а не тихий крах).

Цепочка защищена от дублей и зацикливаний. Если тема из конфига не существует —
резолвер всегда падает на `wiki`.

## Манифест темы

Каждая тема содержит `theme.php`:

```php
return [
    'name'   => 'mytheme',            // имя (совпадает с папкой)
    'parent' => 'wiki',               // родительская тема (null = корень)
    'css'    => ['assets/css/my.css'],// дополнительные css (после базовых)
    'js'     => [],                   // дополнительные js
];
```

- `parent`: тема-основа. `wiki` — `null` (корень).
- `css`/`js`: **дополняют** wядра app.css/JS, не заменяют. Наследуются от родителей.
  Файлы указываются относительно `public/`, поэтому кладите их в
  `themes/{name}/assets/css/*.css` (URL `/assets/...`).

## Создание темы

1. **Папка**: `resources/views/themes/{name}/`.
2. **Манифест**: `themes/{name}/theme.php` с `'parent' => 'wiki'`.
3. **Файлы**: кладите в `themes/{name}/site/...` только то, что меняете.
   Нюанс компоновки:
   - `site/layouts/header.php` — общий каркас (`<head>`, подключение CSS/JS).
     Его переопределять не нужно — лучше менять `site/layouts/partials/header-body.php`
     (тело шапки + навигация).
   - `site/pages/home.php` — главная.
   - `site/layouts/article.php` — просмотр статьи/факта/сайта/страницы.
   - остальное наследуется от `wiki`.
4. **Ассеты**: `themes/{name}/assets/css/*.css` (или `js/`), укажите в `css[]`/`js[]`.
5. **Конфиг**: `config/general.php` → `'template' => '{name}'`.

## Ассеты темы (css/js)

- Базовые `app.css` и JS ядра подключает `wiki/site/layouts/header.php`.
- Свои css/js темы подключаются **после** базовых (через `theme_assets()`),
  поэтому каскад переопределяет базовые правила без `!important`.
- Файлы темы из `themes/{name}/assets/**` копируются в `public/assets/**`
  (`Theme::publishAssets()`). Вызывается при рендере страницы и при статической сборке
  (`BuildController::copyAssetsToStatic()`).
- `<body>` получает класс активной темы (`class="blog"`), поэтому стили можно
  ограничивать `body.blog ...`, не боясь конфликтов с админкой.

## Переключение темы

`config/general.php`:

```php
'template' => 'wiki',   // или 'blog', или имя вашей темы
```

После смены обновите страницу жёстко (Ctrl+F5): номер версии в URL ассетов при
смене темы не меняется, браузер может держать кеш.

## Класс Theme — публичные методы

| Метод | Назначение |
|---|---|
| `Theme::current()` | имя активной темы (фолбэк на wiki) |
| `Theme::manifest()` | манифест активной темы |
| `Theme::chain()` | цепочка тем от активной вверх по родителям |
| `Theme::resolve($path)` | реальный путь шаблона `site/...` |
| `Theme::has($path)` | существует ли файл в цепочке |
| `Theme::css()` / `Theme::js()` | список ассетов темы (с унаследованными) |
| `Theme::publishAssets()` | копирует ассеты темы в `public/assets` |
| `Theme::themeExists($name)` | существует ли каталог темы |

## Интеграция

- `insert()` / `site_view()` в `app/helpers.php` прогоняют пути через `Theme::resolve()`.
- `theme_assets('css'|'js')` рендерит теги `<link>`/`<script>` для ассетов темы.
- Все точки работают одинаково для предпросмотра и статической сборки.

## ВАЖНЫЕ ПРЕДУПРЕЖДЕНИЯ

- **НЕ удаляйте** `themes/wiki` — это аварийный фолбэк и база, на которую падает
  резолвер при любой ошибке конфигурации.
- Тема, переопределяющая **целый** `site/layouts/header.php`, обязана сама отдать
  `<!DOCTYPE>`, `<head>` и подключить `app.css` + `theme_assets()`. Вместо этого
  предпочтительно переопределять только `partials/header-body.php` (каркас наследуется).
- `shared/` и `admin/` **не темизируются** — это общее ядро.

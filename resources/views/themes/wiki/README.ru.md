# Тема оформления «wiki»

Дефолтная тема публичного сайта. Наследуется другими темами (например, `blog`).

## Роль

- Это **корень цепочки тем**: дочерние темы (`themes/blog`) наследуют от `wiki` все файлы, которые не переопределяют сами.
- Если активная тема из конфига не существует или сломана — резолвер **всегда падает на `wiki`** (неприкосновенная база, не должна удаляться).
- Стилизация по умолчанию, набор страниц и компонентов раздела «факты / статьи / сайты / страницы».

## Структура папки

```
resources/views/themes/wiki/
├── theme.php                    манифест темы
└── site/
    ├── layouts/
    │   ├── header.php           общий каркас: <head>, подключение app.css и ассетов темы
    │   ├── footer.php           подвал + Я.Метрика + лайтбокс
    │   ├── article.php          общий layout просмотра статьи/факта/сайта/страницы
    │   ├── sidebar.php          боковая колонка (служебная)
    │   └── partials/
    │       └── header-body.php  «тело» шапки + навигация (его переопределяют темы)
    ├── pages/
    │   ├── home.php             главная
    │   ├── best.php             «лучшие» с пагинацией
    │   ├── page.php             служебная страница (о сайте и т.п.)
    │   ├── facts/{index,view}.php    список/просмотр фактов
    │   ├── articles/{index,view}.php список/просмотр статей
    │   └── sites/{index,view}.php    список/просмотр сайтов
    └── components/
        ├── article-body.php     тело статьи (парсер контента)
        ├── backlinks.php        «сюда ссылаются»
        ├── categories-list.php
        ├── featured.php
        ├── infobox.php          инфобокс записи
        ├── story-list.php
        └── toc.php              оглавление
```

## Манифест

`theme.php` — корень цепочки, `parent` отсутствует (`null`), собственных css/js нет
(базовый `app.css` и ядро js подключаются в `site/layouts/header.php`):

```php
return [
    'name'   => 'wiki',
    'parent' => null,
    'css'    => [],
    'js'     => [],
];
```

> **Важно.** Файлы `wiki` изменять нужно, только если вы правите сам дизайн по умолчанию.
> Чтобы создать собственную тему — делайте копию в `themes/{name}/` и переопределяйте
> только нужные файлы (см. «Система тем» в корневом README каталога `themes`).

## Как разрабатывать тему на базе wiki

1. Создайте `resources/views/themes/{name}/theme.php` с `'parent' => 'wiki'`.
2. Кладите в `themes/{name}/site/...` только те файлы, что хотите изменить
   (например, `layouts/partials/header-body.php`, `pages/home.php`).
3. Остальное наследуется из `wiki` автоматически.
4. Свои стили — в `themes/{name}/assets/css/*.css`, укажите их в `css[]` манифеста.
5. В `config/general.php` поставьте `'template' => '{name}'`.
